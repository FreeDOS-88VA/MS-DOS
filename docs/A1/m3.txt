output-until-busy and prefix count, output status, not ready and write
fault. AUXMCK checks COM1 peek/status/read/flush, raw write including a
high byte, CTS-busy/not-ready, and DOS AH=03h and AH=04h via AUX. Both
isolated fixtures also returned P and exit 0 in emu2, excluding DOS
standard handles. These are synthetic BIOS replies, not byte captures.

Compared with the baseline on both models, CHKDSK conventional memory
is unchanged at 655,360 bytes total and free memory fell 704 bytes (from
524,800). IO.SYS grew 560 bytes on disk. The resident BIOS grew 396 bytes
before rounding; the floppy DOS destination including the alignment
workaround moved by 432 bytes. The free-memory result includes DOS and
is measured, not inferred from the BIOS size.
